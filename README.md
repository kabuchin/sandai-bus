# 産大バス時刻表

大阪産業大学のスクールバス（産大バス）の時刻表を確認できるWebアプリケーションです。リアルタイムで次のバスの時刻と到着までの残り時間を表示します。

## 機能

### 基本機能
- リアルタイム表示: 現在時刻に基づいて次のバスの時刻を自動で表示
- 双方向対応: 産業大学前発とJR住道駅発の両方向のバス時刻に対応
- 残り時間表示: 次のバスまでの残り時間を分単位で表示
- 今後の時刻表示: 今後の発車時刻一覧を確認可能
- ダイヤ判定: 平日・土曜・夏季限定・無料乗車日・運休日を自動判定
- ダークモード: システム設定に応じた自動切り替え、または手動切り替え

## 使い方

### アプリのインストール

#### Androidの場合
1. Chromeでサイトを開く
2. 画面下部に表示される「インストール」バナーをタップ
3. 確認ダイアログで「インストール」をタップ
4. ホーム画面にアイコンが追加されます

#### iPhoneの場合
1. Safariでサイトを開く
2. 画面下部の共有ボタンをタップ
3. 「ホーム画面に追加」を選択
4. 「追加」をタップ

#### デスクトップの場合
1. Chrome/Edgeでサイトを開く
2. アドレスバーのインストールアイコンをクリック
3. 「インストール」をクリック

### 基本操作
1. ページを開くと自動で現在時刻のバス情報が表示されます
2. 次のバスとその次のバスの時刻が大きく表示されます
3. 「今後の発車時刻」をタップすると詳細な時刻表が開きます

### 日時設定機能
1. 左上の日時エリア全体をクリック（またはEnter/スペースキー）してモーダルを開きます
2. 任意の日付と時刻を入力します（入力中にプレビューが表示されます）
3. 「この時刻で表示」ボタンで確定すると、その時刻でのバス情報が表示されます
4. 「現在時刻に戻す」ボタンで現在時刻に戻ります
5. Escキーまたはモーダル外をクリックしてキャンセルできます

### 手動設定時の表示
- 日時エリア全体がオレンジ色の枠で表示されます
- 自動更新は停止し、設定した時刻で固定されます

## 対応ダイヤ

### 平日ダイヤ
- 平日（月〜金）: 通常の授業日程
- 平日特別ダイヤ（臨時増便）: 4/2〜5/1・9/24〜10/2 などの期間限定で増便運行（`day.json`の`weekday_special_schedule`で年ごとに設定）

### 土曜ダイヤ
- 土曜日: 土曜授業日の運行

### 特別ダイヤ
- 夏季限定ダイヤ: 夏季休暇期間中の限定運行
- 無料乗車日: 大学祭などの特別イベント日
- 運休日: 日曜日・祝日・長期休暇期間

## 技術仕様

### PWA機能
- Service Worker: オフラインサポートとキャッシュ管理
- Manifest: インストール可能なアプリケーション設定
- キャッシュ戦略:
  - HTML（ナビゲーション）: ネットワークファースト（オフライン時はキャッシュ、それも無ければindex.htmlにフォールバック）
  - JSONデータ・CSS・JS: Stale-While-Revalidate（キャッシュを即座に返しつつバックグラウンドで更新）
  - 画像などその他の静的ファイル: キャッシュファースト

### パフォーマンス最適化
- リソースヒント: preload, preconnect, dns-prefetch
- 遅延読み込み: 非必須機能の遅延初期化
- Debounce機能: 入力中の処理を最適化
- 効率的な表示更新: 必要な部分のみ更新、スクロール位置を保持したまま再描画

### コード品質
- 入力検証: 堅牢なデータ検証機能
- エラーハンドリング: 包括的なエラー処理（エラー表示はDOM構築によりXSSを防止）
- モジュール化: 機能ごとに分離された関数構成
- アクセシビリティ: ARIA属性とキーボード操作対応（タブ開閉・モーダルのフォーカストラップを含む）

### ファイル構成

```
├── bot_bus.webp        # アプリアイコン

```

### データ形式
- time.json: 各ダイヤタイプの時刻表データ
- day.json: 年間の特別ダイヤスケジュール

### 外部ライブラリ
- qrcode（node-qrcode UMDビルド, jsdelivr CDN経由）: QRコード生成ライブラリ
- Google Fonts: Noto Sans JPフォント

### API利用
- Web Share API: ネイティブ共有機能（対応デバイスのみ）
- Clipboard API: URLコピー機能
- beforeinstallprompt: PWAインストールプロンプト

### ブラウザ対応
- Chrome, Firefox, Safari, Edge の最新版
- iOS Safari (13.0+), Android Chrome (84+)
- PWA（Progressive Web App）として動作可能

## カスタマイズ

### 時刻表データの更新
1. `time.json`で各ダイヤの時刻を編集
2. `day.json`で特別ダイヤの適用日を設定

### 表示設定の変更
- `upcomingBusCount`変数で表示する今後のバス本数を調整
- CSS変数でカラーテーマのカスタマイズが可能

### Service Workerのバージョン管理
- `sw.js`の`CACHE_NAME`を変更してキャッシュを更新

## トラブルシューティング

### アプリが更新されない
1. メニューから「更新」を選択
2. ブラウザのキャッシュをクリア
3. アプリを再インストール

### オフラインで動作しない
1. 一度オンライン状態でアクセスしてキャッシュを作成
2. Service Workerが正常に登録されているか確認
3. ブラウザの設定でService Workerが有効になっているか確認

### インストールバナーが表示されない
1. 既にインストール済みの可能性があります
2. iOS Safariの場合は共有メニューから手動で追加
3. 最近閉じた場合は7日後に再表示されます

### v1.1.1 (2026-07-05)

**時刻表ロジックの重大バグ修正**
- 平日ダイヤと臨時増便ダイヤの時刻表ID取り違え（1-A/1-B逆転）を修正。通常の平日に誤って臨時増便ダイヤが適用されていた問題に対応

**更新・オフライン挙動の修正**
- Service Workerの二重登録と、初回訪問時に画面が勝手にリロードされる不具合を修正
- オフライン時にキャッシュが無いとエラーになる不具合を修正し、真っ白画面を防止
- Service Workerのキャッシュ戦略を見直し（HTML:ネットワークファースト、JSON/CSS/JS:Stale-While-Revalidate）
- requestIdleCallback未対応ブラウザ（iOS Safari等）で二次機能が初期化されない不具合を修正

**UI/UXの改善**
- モバイルでURLバーの表示/非表示によりタブが勝手に閉じる不具合を修正
- ピンチズームを禁止していたviewport設定を解除
- 「今後の発車時刻」リストのスクロール位置が毎分リセットされる不具合を修正
- 本日の運行終了後に「明日の始発」時刻（運休日なら運休の案内）を表示するように改善
- 入力エラー表示をalert()からトースト通知に変更
- タブ開閉・モーダルにキーボード操作、ARIA属性、フォーカストラップを追加
- ローディング画面が読み込み失敗時に固まったままにならないようタイムアウト処理を追加
- インストール案内バナーに閉じるボタンを追加し、7日間の再表示制御を実装
- 表示更新タイマーを分境界に同期し、残り時間表示の最大59秒のズレを解消
- QRコード生成ライブラリをnode-qrcode UMDビルドに差し替え（CDN 404エラーを修正）

**コード品質・セキュリティ**
- エラー表示をinnerHTMLからDOM構築に変更し、XSSリスクを排除
- 重複していたトースト表示関数や未使用の死にコードを削除
- manifest.jsonのアイコンサイズ指定の不備を修正（PWAインストール条件を満たすように）
- 外部リンクに`rel="noopener noreferrer"`を追加し、自己参照リンクを削除
- インラインCritical CSSがstyles.cssを恒久的に上書きしていた問題を解消
